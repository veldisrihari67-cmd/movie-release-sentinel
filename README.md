# 🎬 The Movie Release Sentinel

Welcome to the Movie Release Sentinel! This is an automated, no-code project designed to keep track of upcoming movie releases and archive movie data by specific months and years.

## 🚀 Features (Coming Soon)
*   **Daily Updates:** Automatically fetches the latest "Upcoming Movies" data every single day.
*   **Time Machine:** A manual trigger to search for movies released in specific past or future months.
*   **Web View:** A clean interface to view the fetched data.

## 🛠️ Built With
* GitHub Actions
* TMDB API
